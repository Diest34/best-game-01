Neon Breaker: a neon breakout game. Bounce the ball off the paddle, break every brick across 3 levels, catch falling power-ups (wide paddle, multi-ball, laser, slow ball), build combos and don't drop the ball. Original code, art and sound — no libraries, no network, everything synthesised or drawn in code.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Move with the mouse or ← →, launch and fire the laser with Space or click, P pauses.
